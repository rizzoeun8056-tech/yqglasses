How to Use a Cake Knife and Server Set

A few practical steps for cutting, lifting and serving a slice.

On this page

  2. Cut, then support
  3. Keep the blade clean
  4. Care for the complete set

Plan your portions

Choose slice sizes around the cake’s shape, height and number of guests. For a tiered cake, ask the cake maker about boards, supports and serving order before cutting.

Cut, then support

Use a suitable knife to separate the portion fully. Slide the server underneath to support the slice, then move it close to the plate before setting it down.

Keep the blade clean

Clear frosting and crumbs between cuts. Where a warm blade suits the cake, warm it and wipe it dry before cutting.

Care for the complete set

Follow the care instructions for the selected finish, handle and decoration. Confirm dishwasher suitability for the complete product rather than the metal alone.
