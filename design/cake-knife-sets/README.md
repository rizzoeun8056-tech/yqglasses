# Cake knife and server page

Local route: `/cake-knife-server-sets/`

Six sections: stock/custom hero, collection, surface customization, packaging, team, and lead times/inquiry.

## Verified locally

- Stock/custom tabs change the headline, photograph, timing and relevant inquiry links.
- Arrow keys switch the tabs and update the selected state.
- A product inquiry prefills category, order type and design reference.
- The minimum-order disclosure expands normally.
- Desktop and 390 px mobile layouts have no horizontal overflow; product photographs load.
- The page retains `noindex, nofollow`.

No inquiry email was sent during UI checks. PHP is unavailable in the local runtime, so the optional email-context additions require the usual Hostinger PHP runtime.

Images are resized WebP exports of the supplied knowledge-base photographs. `image-exports.json` records their sources and dimensions.
