# 博客资料投放区

每篇文章在此新建一个文件夹，建议用英文短名，例如 `champagne-flute-care`。

```text
incoming/blog/champagne-flute-care/
├── article.md
├── featured.jpg
└── images/
    ├── detail-01.jpg
    └── detail-02.jpg
```

- `article.md`：完整原稿。正文插图使用相对路径，例如 `![图片说明](images/detail-01.jpg)`。
- `featured.jpg`：指定的文章主图；也可使用 PNG、WebP，并在消息中告知文件名。
- `images/`：其他原始图片。原稿和原图会保留，网页用图另行导出。

放好后，把文章文件夹路径发给我，并告知分类（Champagne Glassware 或 Cake Knife Set）及成稿语言。我会先做本地博客预览。
