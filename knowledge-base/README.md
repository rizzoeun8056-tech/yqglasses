## 使用方式

1. 编写相关分类页、产品页、博客或 FAQ 前，先查阅对应知识条目。
2. 区分行业常识、参考品牌自身的产品信息、YQ 已确认规格和编辑建议。其他品牌的参数、测试结果、交期与服务不可直接写成 YQ 的承诺。
3. 产品材质、尺寸、起订量、工艺、包装、食品接触检测和清洗适用性，以 YQ 实物、供应商资料或相应检测文件为准。没有确认的数据保留“待确认”。
4. 参考文章只提取与产品有关的信息；不纳入促销、导航、购物弹窗和无关商品推荐。英文网站文案重新组织表达，不照搬竞争品牌的叙述。
5. 新增条目时记录来源、整理日期、核验状态，并更新本索引。
6. 品牌方后续确认的通用供货和定制能力，以 [YQ 产品与服务确认记录](company/yq-cake-knife-server-capabilities.md) 为当前依据；此前竞品文章中的“待 YQ 确认”状态不覆盖后续品牌方的直接确认。具体 SKU 参数和订单细项仍分开核对。
