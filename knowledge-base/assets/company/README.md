## 页面选图规则

- 优先用 001 展示办公室，用 008 展示展厅通道，用 009 展示刀铲选款桌，用 012 展示人工加工工作台。
- 002 与 005、010 与 015、011 与 013 为相近场景的不同构图，同一区块按横竖版式择一，避免重复。
- 003 为刀铲工作台操作照片，具体作业职责未标注；014 为机台操作照片，具体设备与工序名称以品牌方确认信息为准。
- 015 左下角有场景内二维码，网页排版时可选择不含该角落的取景；本素材保留完整实拍内容。
- 品牌方确认这些照片属于 YQ GLASSES 的公司与加工工厂场景。工厂归属、占地面积、人员数量、设备产能、生产周期和认证资质仍按各自确认资料使用，照片不替代相关参数。
- 横向图适合图文双栏；竖图适合细节和画廊；方图适合卡片。展示人物、工具和产品时优先保留主体完整轮廓。
