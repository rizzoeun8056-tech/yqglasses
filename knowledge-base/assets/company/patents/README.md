## 图片处理与原件

- 两张候选图片均为 WebP，宽高不超过 600px，单张小于 40,000 字节。
- 按完整页面等比缩小与压缩，保留页面边缘、全部文字、印章、水印、二维码、条形码和页码。
- 原始 JPEG 均为 800 × 1131px，继续保存在用户提供的原位置；来源路径、原图哈希及成品哈希见 [manifest.json](manifest.json)。
- 600px 版本适合作为证书卡片或画廊预览。若后续页面需要放大阅读正文，应另行使用保留的原始文件。
- 本目录属于内部素材库，不会随 Astro 构建直接成为公开网页。
