## 2. 产品定义与准确叫法

本文讨论的典型产品是由 **一把蛋糕刀和一把蛋糕铲** 配成的两件套：前者负责切分，后者负责承托和转移蛋糕。两件工具的外观、手柄与表面处理通常采用协调设计。

| 英文用语 | 建议中文 | 使用说明 |
|---|---|---|
| Cake knife | 蛋糕刀 | 主要用于切分蛋糕 |
| Cake server | 蛋糕铲／分蛋糕铲 | 主要用于承托、提起和转移蛋糕片 |
| Cake knife and server set | 蛋糕刀铲套装 | 最明确地描述本文两件套产品，适合作为页面主名称 |
| Cake knife set | 蛋糕刀套装 | 常见检索词，需在详情中交代具体包含物 |
| Cake cutting set | 切蛋糕套装 | 可用于婚礼、庆典等场景描述 |
| Cake serving set | 蛋糕分餐套装／蛋糕刀铲套装 | 含义可能更广，需要注明套装件数 |
| Wedding cake knife and server set | 婚礼蛋糕刀铲套装 | 婚礼用途的明确表达 |
| Serrated edge | 锯齿刃 | 描述刃口形态，不是所有蛋糕刀或蛋糕铲的必备特征 |

**术语纠正：**不要将 `cake knife and server set` 译成“蛋糕刀叉套装”。`Server` 在这里是蛋糕铲，不是叉子；也应避免使用容易被理解为抹奶油工具的“抹刀”作为主名称。

## 3. 组成、结构与选购价值

| 部件／结构 | 主要作用 | 值得关注的项目 |

## 4. 材质与表面工艺

### 4.1 不锈钢：分别确认刀刃和手柄

“不锈钢”是材料类别，不能单凭这个名称判断切割性能或清洗方式。18/8、18/10 常见于餐具语境，但不能仅凭此类标识认定刀刃具备更高硬度或更好的刃口保持能力。BSSA 说明，可通过热处理硬化的马氏体不锈钢可用于刀刃；刀刃与手柄可能采用不同材质。[BSSA 材质说明](https://bssa.org.uk/bssa_articles/cutlery-stainless-steel-grades/)

采购时应分别记录：**刀刃材质、蛋糕铲材质、手柄材质与表面处理**，避免用整套餐具的笼统标识代替各部件规格。

### 4.2 银色、金色、镀层与 PVD 不能混为一谈

| 表述 | 应如何理解与核实 |
|---|---|
| 银色外观 | 是颜色描述，不代表纯银或镀银 |
| 金色／玫瑰金外观 | 是颜色描述，不代表含金，也不能据此确定采用电镀还是 PVD |
| 镀银／纯银 | 是不同材料或结构方案，需分别核实；不能只按外观判断 |
| PVD | 是表面处理工艺，不能单凭该名称承诺永不磨损、永不脱落或所有使用条件下均适用 |
| 抛光、拉丝、锤纹等 | 主要描述外观或表面效果，不等同于独立的材料牌号 |

品牌的实际护理要求可能不同：Sambonet 为其 PVD 产品提供有条件的机洗指导，并提示磨料可能损伤涂层；solex 则建议其 PVD 餐具手洗，并限制耐久性承诺。因此，是否可用洗碗机应按**具体成品**判断，不能推广成所有 PVD 产品的共同属性。[Sambonet 官方护理说明](https://www.sambonet.com/en-gb/product_care.html)、[solex 官方护理说明](https://solex.de/en/inspiration/design-pvd/)

食品接触适用性也不能从“不锈钢”“金色”或“PVD”几个词直接推导。YQ 对外采用相关声明前，应核对具体成品的材料、涂层、适用部位及相应文件。

## 5. 使用方法：切、托、移、放

以下是适用于相应蛋糕和刀具的通用操作参考，不是所有蛋糕都必须采用的固定方法。

1. **准备刀刃。**对于适合温刀切割的糖霜或奶油表面，可用温水略微温热刀刃后彻底擦干；不需要把装饰手柄一起浸入水中。
2. **轻柔切分。**使用适合的刀刃切出完整蛋糕片。锯齿刀可采用轻柔锯切动作，减少切割时的拉扯。
3. **逐刀清洁。**每切完一片，清除刀刃上的奶油和碎屑，避免后续切口被残留物拖抹。
4. **充分承托。**将蛋糕铲滑入已分离的蛋糕片下方，尽量支撑其底部；转移较高的蛋糕片时，用另一工具轻轻稳定。
5. **贴近餐盘放下。**让蛋糕片接近盘面后再轻轻滑下，减少转移距离，避免用力挤压。

温刀、擦干、切片间清洁与轻柔锯切等技巧参考 King Arthur Baking 的切蛋糕指导；实际选择仍应结合蛋糕质地和刀具特点。[切蛋糕技巧](https://www.kingarthurbaking.com/blog/2019/05/21/how-to-cut-a-cake)

圆形、方形及堆叠多层蛋糕的分餐信息、份量示例与第二篇参考文章的纠错记录，见 [蛋糕刀铲使用与分餐指南](../guides/cake-cutting-serving.md)。

## 6. 清洗与保养

- 用后及时清除食物残留；清洗后充分擦干，再存放。
- 对装饰手柄、拼接结构或表面处理尚未确认的产品，可先采用温和手洗建议，待取得型号护理说明后再明确。
- 不要因为是金属餐具，就默认适合长时间浸泡、强力清洁剂、磨料刷洗或洗碗机。
- 带镀层、装饰或其他复合材料的成品，需要同时考虑各部件的护理要求。
- “可机洗”必须是具体产品的适用说明；不能把其他品牌的声明转用于 YQ。

以上护理原则参考餐具品牌对不锈钢与 PVD 产品的指导，不能替代具体型号的说明。[Sambonet 官方护理说明](https://www.sambonet.com/en-gb/product_care.html)

## 9. FAQ 知识要点

**Q：一套 Cake Knife & Server Set 包含什么？**  
A：本文讨论的典型两件套包含蛋糕刀和蛋糕铲。实际销售套装的件数和附件需以产品说明为准。

**Q：蛋糕刀和蛋糕铲各自有什么作用？**  
A：刀负责切分，铲负责承托并转移切好的蛋糕片；二者共同完成切分到装盘的过程。

**Q：是不是必须选择锯齿刀？**  
A：不能一概而论。锯齿刃适用于一些切割场景，选择时还应考虑蛋糕类型、刀刃设计与实际使用表现。

**Q：18/10 是不是任何蛋糕刀的最佳材料？**  
A：不能这样判断。刀刃与手柄需要分别评价，材料牌号、结构和加工方式都可能影响表现；见第 4 节的材质核验说明。

**Q：金色是否代表镀金或 PVD？**  
A：不代表。颜色与工艺是不同信息，需要供应商确认具体表面处理。

**Q：是否可以用洗碗机？**  
A：取决于具体产品的材料、表面处理、装配方式和护理说明。未经型号确认，不作统一承诺。

**Q：婚礼用途应该关注什么？**  
A：外观协调、握持空间、使用平衡和礼品包装。两人握持适用性等体验应看样确认。
